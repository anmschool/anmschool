# 경배와찬양학교 시즌 운영 체크리스트

담당자가 바뀌어도 이 순서대로 하면 시즌을 열고 닫을 수 있게 정리한 문서입니다.

## 0. 구조 한눈에
- **웹(자동 배포)**: GitHub `anmschool/anmschool` → Vercel `anmschool.vercel.app`
  - `/` 메인 앱 · `/apply` 온라인 신청서 · `/linkhub` 링크 모음 · `/linkhub/about.html` ANM 소개
- **Apps Script(anmschool 계정, 한 프로젝트)**: `01`~`04`, `06_ops.gs`
  - 04 = 앱 API(로그인·신청·내용) · 03 = 운영 시트 동기화(5분) · 06 = 알림·로그인 캐시·백업
- **시트**: 'ANM 앱'(공지·시간표·안내·장소·프로젝트) · 「YYYY 등록·재정·숙소」(운영) · ANM_DB(누적)

## 1. 시즌 열기 (신청 오픈 2주 전)
1. 운영 시트 복사 → 이름을 새 시즌으로, 'ANM 앱' 프로젝트 탭에 새 행(ID·날짜·장소·운영 시트 ID·로그인 ON)
2. 운영 시트 **트랙** 탭: 트랙 이름·키워드·입실/퇴실·계좌 / **금액** 탭: 선등록·일반 금액 / **설정** 탭: 선등록 마감
3. 신청서(`anm-app/public/apply/index.html`)와 메인 앱(`src/pages/Home.tsx`)의 트랙·날짜·요금 문구 수정
4. Apps Script 코드를 저장소 사본과 맞춘 뒤 **배포 → 배포 관리 → 새 버전**
5. `setupOpsTriggers()` 실행(로그인 캐시·백업·일일 요약), 동기화 트리거 확인
6. **테스트 신청 1건**(개인·단체 각각) → Master_DB 코드·숙소 줄·텔레그램 알림 확인 → 테스트 행 삭제
7. Linkhub·신청서·메인 웹을 폰과 PC에서 한 번씩 열어 보기

## 2. 신청 기간 중 (매일)
- 텔레그램 아침 요약 확인 (새 신청·미입금·실패)
- 입금 확인은 수작업(모임 방침): 통장 내역 → 「훈련비 입금」 탭 1건 1줄
- 숙소: 「숙소 미배정」 탭에서 동·호실 입력

## 3. 일정·트랙이 바뀔 때
- 운영 시트 트랙 탭 날짜 → `rebuildNightTable` 실행
- 신청서·메인 앱 문구, 'ANM 앱' 프로젝트/시간표 탭, Memo·신청서 Doc·홍보물 함께 수정

## 4. 시즌 닫기
- 'ANM 앱' 프로젝트 상태를 '종료'로 → 신청 버튼 자동으로 숨김
- 운영 시트 「설정」 자동 동기화 OFF, 최종본은 'ANM 백업' 폴더에 남아 있음(14일 보관 → 필요하면 별도 보관)

## 5. 비상 연락·권한

- 텔레그램 토큰은 Apps Script **스크립트 속성**(TG_TOKEN·TG_CHAT)에만 있음
